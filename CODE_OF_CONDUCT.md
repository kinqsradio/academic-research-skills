# Community code of conduct

This policy applies to issues, pull requests, reviews, and other project spaces, including maintainers and contributors.

## Expected behavior

Treat people with respect. Critique claims and code with specific evidence, explain disagreements clearly, and accept good-faith corrections. Welcome contributors with different backgrounds and levels of experience. Respect source attribution, copyright, personal privacy, and research confidentiality.

Harassment, discrimination, threats, sexualized conduct, personal attacks, deliberate disruption, and publishing someone's private information without permission are unacceptable. Do not post credentials, confidential research, or participant data in public discussions.

## Reporting and moderation

Use GitHub's reporting tools for abuse or threats. To raise a project conduct concern with the maintainer, ask `@kinqsradio` for a private reporting channel without posting sensitive details publicly. For security vulnerabilities or accidental exposure of secrets, use the separate [security policy](SECURITY.md).

Maintainers may remove content, lock discussions, warn participants, or restrict participation according to the conduct and its impact. They should apply these rules consistently and explain moderation decisions where doing so respects privacy. No response-time guarantee is made. See [GitHub's guidance for reporting abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
