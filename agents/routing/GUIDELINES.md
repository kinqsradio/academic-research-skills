# Agent model routing

This folder holds the provider-neutral [routing index](MODEL_ROUTING.md) and the [Codex](CODEX.md) and [Claude](CLAUDE.md) worker model and effort policies. Start with the index, then read only the guide for the active provider. The human-selected lead model and effort are outside these worker limits.

Keep role responsibilities and handoff requirements in [the parent team guide](../README.md). Update these three files and all inbound links together when routing changes; record actual session availability and validation separately from documented recommendations.
