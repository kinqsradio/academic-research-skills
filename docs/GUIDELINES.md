# Research documentation

Store project records by purpose rather than by the tool or person that produced them. Manuscript text and formal reviews belong in submissions/.

| Folder | Document types |
| --- | --- |
| [planning](planning/GUIDELINES.md) | Questions, scope, milestones, task plans. |
| [literature](literature/GUIDELINES.md) | Searches, source notes, evidence tables, synthesis. |
| [methods](methods/GUIDELINES.md) | Design choices, protocols, analysis plans, reproducibility. |
| [decisions](decisions/GUIDELINES.md) | Accepted decisions, alternatives, rationale, open questions. |
| [operations](operations/GUIDELINES.md) | Setup, compatibility, maintenance, validation. |

Each document should identify its purpose, status, and relevant date or version. Link related records; avoid duplicate authoritative instructions. Add a category only for a distinct recurring document type, with its own GUIDELINES.md.
