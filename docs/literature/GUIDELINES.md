# Literature records

Keep search logs, reading notes, evidence tables, and cross-source synthesis here. Link each source to its papers/ file or stable source URL. Record what was searched, when, and with which selection criteria. Give locators for material claims; distinguish full-text reading from abstracts or secondary reports. A narrative collection is not an exhaustive systematic review. Manuscript-ready prose belongs in submissions/drafts/.

Use the stable source IDs in [the download register](../../papers/DOWNLOADS.md), and link to [IEEE reference metadata](../../papers/REFERENCES.md). Keep evidence locators separate from bibliographic verification. If a note has a numbered bibliography, number it by its own first-citation order.
