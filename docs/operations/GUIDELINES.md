# Operations navigation

Use these purpose-based folders for reusable operations guidance:

| Folder | Contents |
| --- | --- |
| [branching](branching/GUIDELINES.md) | Template and research branch procedures, promotion, and synchronization. |
| [setup](setup/GUIDELINES.md) | Assistant setup, model-selection evidence, and compatibility checks. |

Keep this category root as navigation. Put new maintained operations content in the matching subfolder, or add a named subfolder with its own GUIDELINES.md when a distinct recurring purpose emerges. Project-specific setup audits, validation evidence, and decisions belong on the relevant `research/<project>` branch. Distinguish documentation-based compatibility, local checks, and live execution. Record commands, dates, versions, limits, and actionable follow-up without credentials or machine-specific configuration.
