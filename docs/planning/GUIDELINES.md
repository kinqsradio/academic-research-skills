# Planning records

Keep research questions, task plans, scope boundaries, milestones, and resource estimates here. State the owner, intended output, inputs, dependencies, and current status. Separate proposed activities from completed work. When scope changes, record the decision and its effect on existing tasks; keep decisions with lasting rationale in docs/decisions/.

For delegated work, record the human-selected lead model and effort when exposed, worker assignments and bounds, exact output ownership, acceptance criteria, and review status. Workers execute the scoped tasks; the lead guides them, checks receipts and consequential evidence, and integrates results. Do not treat planned model settings as verified runtime settings.
