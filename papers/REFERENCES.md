# IEEE reference catalog

No references are recorded in the template. Populate this catalog only on a research branch under [paper guidance](GUIDELINES.md), together with [DOWNLOADS.md](DOWNLOADS.md).

For each work add a heading such as `## P001`, its IEEE-formatted reference, a local file link, version/access status, bibliographic verification source and locator, and unresolved metadata. A failed retrieval without verified identity need not have a completed reference. Never invent fields. Catalog positions are independent of manuscript citations, which follow first-citation order.

PDFs stay local and ignored on every branch. Commit references on the research branch and preserve them when local files are absent.
