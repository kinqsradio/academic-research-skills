# Academic-paper skill guidelines

Maintain an original, English workflow for scholarly drafting and revision. `SKILL.md` is the entrypoint; `argument-and-revision.md` supplies the working method. Keep guidance compatible with both Codex and Claude through capability descriptions rather than proprietary tool names.

Place research artifacts in the repository's designated `docs/` and `submissions/` folders, not here. Add a resource only when it helps a repeated writing decision. Update relative links with any rename. If a new subfolder is necessary, give it its own `GUIDELINES.md`.

Use the canonical [paper guidance](../../papers/GUIDELINES.md), [download register](../../papers/DOWNLOADS.md), and [reference catalog](../../papers/REFERENCES.md) for source identity and provenance. Keep stable paper IDs separate from artifact-specific IEEE citation numbers. Update relevant supporting records when changing this workflow. The lead coordinates and checks scoped worker outputs; workers do not delegate further. Human-selected lead model and effort remain outside subagent routing limits.
