# Optional Orbyn reconciliation

Maintain the portable Orbyn reconciliation procedure in `SKILL.md`. It is read directly by path in Codex or Claude; this folder does not install a connector, define a fixed tool schema, or store project records.

Keep examples generic and free of credentials or personal account IDs. Current tool descriptions govern actual operations. For an accessible project, reconcile native briefs, rubrics, documents, tasks, and user edits with repository records on each active invocation or resume, preserving source versions and status in the appropriate `docs/` folder. Do not describe this as automatic background monitoring.

The repository's Markdown, evidence, and decision records on `research/<project>` remain authoritative for research content; native Orbyn material is an external source that must retain provenance. Keep PDFs local in `papers/`. Maintain a usable repository-only path when access or a needed permission is unavailable, and distinguish applied changes from proposals pending review.
