# Skill-authoring folder

Maintain the team's original, English skill-authoring workflow here. `SKILL.md` is its only entrypoint; this folder contains reusable instructions, not research records or generated user artifacts. Keep it usable by Codex and Claude through explicit file-path invocation and available capabilities.

Use examples only when they clarify a real authoring decision. Add supporting files when they have a demonstrated repeated use; add GUIDELINES.md to each new maintained subfolder. Keep relative links and the parent skill index current. Do not copy provider manuals, introduce hidden adapters, or imply automatic host registration. Validate structure and demonstrate behavior separately; neither proves live host compatibility.
