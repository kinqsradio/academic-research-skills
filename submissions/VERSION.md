# Submission version record

No submission artifacts or submission events are recorded yet. The existing `version/` directory is reserved for preserved snapshots.

## Version convention

Use `submissions/version/v001/`, `v002/`, and subsequent sequential directories for review or submission snapshots. Keep draft and exported files together when practical. Never overwrite a snapshot already reviewed or submitted; create a new version and explain the changes.

Use repository-relative paths in the record. Track artifact status separately from review and submission events; `draft`, `in review`, `approved`, and `submitted` describe different states. Only mark a version submitted after the actual submission is confirmed.
